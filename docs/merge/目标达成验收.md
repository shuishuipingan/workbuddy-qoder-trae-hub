## 这 101 轮改了什么（按类）

### 一、真实缺陷（都是实测发现，不是读代码猜的）

| 缺陷 | 症状 |
|---|---|
| **表头排序是死的** | 点「上下文」纹丝不动 —— 注释声称 `ui.table` 会处理点击，而它从来没接过线 |
| **顶栏主题 / 语言按钮是死的** | 点下去没反应 —— 根因是 **buildTopbar 被调两次导致双绑**，一次点击跑两遍 handler |
| **`Alt+N` 切档不改地址栏** | 刷新就跳回原视图、复制 URL 指向错的页 |
| **复制按钮会卡死** | 文档失焦时 `clipboard.writeText` 的 promise **永不 settle** → 按钮永远没有反馈 |
| **登录可能永不返回** | 侧请求 `fetch` 没有超时，而它在 `login()` 里被 await |
| **模态会堆叠** | 连点 3 行堆 3 个弹窗，关掉一个露出下一个 |
| **窄屏顶栏与导航之间有 25px 的缝** | 表单输入框从缝里穿过去 |
| **窄屏侧栏占 309px 高却什么都不显示** | 内联 `flex-direction` 压过了媒体查询 |
| **命令面板搜不到 `logs`** | 只搜中文 label，不搜英文 id |
| **聚合缺一半时不吭声** | qd 挂掉时模型清单 47→28，界面一个字都不提 |

## 已知的、留着没做的（如实列出）

1. **Vue 版只覆盖模型清单一页** —— 迁移建议是逐页做，见 `Vue方案评估.md`。
2. **`data-action` 是个只写不读的记号**（3 处）—— 无害，且它记录了「这个按钮触发哪个动作」，**故意保留**。
3. **`formatCompact` / `badgeHtml` 两个导出从未被使用** —— 记录在案，未删（可能是给后续页面的）。

## 方法上留下的东西

这 101 轮里，**同一个错误形态出现了 8 次**，每次都记下来了：

```
「清了缓存」≠「确认了版本」
「判据在这页成立」≠「在别的页也成立」
「模拟了故障」≠「目标链路真的断了」
「行盒 >1」≠「断行」（可能是标签 + 值，也可能是组件的内部结构）
「按宽度写」≠「按输入设备写」
「文案里有导出」≠「它是导出按钮」
「有没有变化」≠「能不能用」（no-op 会伪装成死控件）
「判据绿了」≠「判据能抓到东西」← 只有阳性对照能区分
```

**而阳性对照否掉了 4 条判据的中间版本** —— 其中一条（C40b 的第二版）**是绿的但完全无效**：
它只问「函数里有没有守卫」，于是撤掉任何一个守卫它都照样绿。

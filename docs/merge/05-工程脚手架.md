### 1.2 `.gitattributes`：原样保留（12 行）

qoder 现有版本有**实测依据**，直接留：

```gitattributes
# 行尾策略（喵萌重工 · 拿铁 / task-11）—— 原文保留
#
# 背景：本机 core.autocrlf=true 且此前没有 .gitattributes，qoder_catalog.py 工作树
#       为 CRLF；而 _refresh_catalog.py 以通用换行读入 + newline="\n" 写回
#       （_refresh_catalog.py:133 读 / :171 写），刷新一次就把该文件归一为 LF，
#       于是每次刷新都会混入「字节级行尾噪声」。
# 策略：Python 源码与模型快照统一在工作树固定 LF。
# 范围：只声明 *.py 与 *.json 两类，属最小侵入；不写 text=auto。
*.py text eol=lf
*.json text eol=lf
```

**为什么不扩范围**：一旦把 `.md` `.html` `.bat` 纳入，历史文件会在首次大规模 `git add` 时产生海量行尾 diff。`.bat` 尤其危险（cmd.exe 对 CRLF 敏感，见 §2.2 的 ASCII 约束）。**保持最小侵入。**

## 2. 启动器：一条命令起双引擎

### 2.1 为什么能统一：两边 CLI 参数集实测对齐

| 参数 | wb（`wb_proxy.py:9690 _parse_cli_args`） | qoder（`qoder_proxy.py:7225`） | 结论 |

### 2.2 终局启动器 `start-hub.bat`

> 约束来自 `start-wb-proxy.bat:7-12` 与 `start-qoder-proxy.bat:7-12` 的既有注释，草案严格遵守：
> ① **全 ASCII**（.bat 按控制台代码页读取，非 ASCII 破坏解析）；
> ② **if( … ) 块内不放 `%VAR%`**（路径含 `(`/`)` 会破坏 cmd 解析）；
> ③ 所有判断走 `if / errorlevel / goto`。

> ⚠️ **落盘说明**：下面代码块为在 Markdown 里安全展示，`%` 被写成 `%%`。**实际写文件时把所有 `%%` 还原成 `%`**（`%%~dp0` → `%~dp0`、`%%PORT%%` → `%PORT%` 等）。两处例外保持原样：`%%~1` 在 `set "PORT=%~1"` 里、`%%%%D` 在 `for /d` 里 —— 也一并按上面规则还原。

```bat
@echo off
setlocal EnableExtensions
rem ===========================================================
rem  hub - unified launcher (WorkBuddy + Qoder, one process)
rem  Usage: double-click, or  start-hub.bat [port]
rem
rem  ASCII-only on purpose: .bat files are read using the
rem  console code page, so non-ASCII text breaks the parser.
rem
rem  NOTE: no %%VAR%% inside an if( ... ) block, because a path
rem  containing ( or ) breaks the cmd.exe parser.
rem ===========================================================

set "PORT=%~1"
if "%%PORT%%"=="" set "PORT=8789"
set "HERE=%~dp0"
set "SCRIPT=%%HERE%%hub\server.py"

if not exist "%%SCRIPT%%" goto no_script

set "PYEXE="

rem ---- 1) bundled runtime (ships with the zip) ----
if not exist "%%HERE%%python\python.exe" goto try_path
"%%HERE%%python\python.exe" --version >nul 2>nul
if errorlevel 1 goto try_path
set "PYEXE=%%HERE%%python\python.exe"
goto run

:try_path
rem ---- 2) python on PATH (>= 3.9 required) ----
python --version >nul 2>nul
if errorlevel 1 goto try_py
set "PYEXE=python"
goto run

:try_py
rem ---- 3) py launcher ----
py --version >nul 2>nul
if errorlevel 1 goto try_codex
set "PYEXE=py"
goto run

:try_codex
rem ---- 4) Codex bundled runtimes ----
call :find_codex
if defined PYEXE goto run

echo [ERROR] No usable Python found.
echo.
echo Options:
echo   1. Use the packaged zip, which already contains python\
echo   2. Install Python 3.9+ from https://www.python.org/downloads/
echo      (tick "Add python.exe to PATH" during setup)
echo   3. Edit this file and set PYEXE to a full path
echo.
pause
exit /b 1

:no_script
echo [ERROR] hub\server.py not found next to this script.
echo         expected: %%SCRIPT%%
echo.
pause
exit /b 1

:find_codex
if not exist "%%USERPROFILE%%.cache\codex-runtimes" goto :eof
for /d %%%%D in ("%%USERPROFILE%%.cache\codex-runtimes\*") do call :probe "%%%%~D"
goto :eof

:probe
if defined PYEXE goto :eof
for /f "delims=" %%%%P in ('dir /b /s "%%~1\python.exe" 2^>nul') do call :probe_one "%%%%~P"
goto :eof

:probe_one
if defined PYEXE goto :eof
"%%~1" --version >nul 2>nul
if errorlevel 1 goto :eof
set "PYEXE=%%~1"
goto :eof

:run
echo ===========================================================
echo   hub gateway  (WorkBuddy + Qoder)
echo.
echo   API      : http://127.0.0.1:%%PORT%%/v1
echo   Admin    : http://127.0.0.1:%%PORT%%/admin/
echo   Legacy   : http://127.0.0.1:%%PORT%%/          (302 to /admin/)
echo.
echo   Python   : %%PYEXE%%
echo.
echo   Keep this window open. Closing it stops the server.
echo   Press Ctrl+C to stop.
echo ===========================================================
echo.

"%%PYEXE%%" "%%SCRIPT%%" --port %%PORT%%
set "RC=%%ERRORLEVEL%%"

echo.
echo [server exited with code %%RC%%]
pause
exit /b %%RC%%
```

`set "RC=%ERRORLEVEL%"` 是**新增行**（现有两个启动器都没有），用于把退出码传给父进程 / CI。

### 2.3 过渡期启动器 `start-hub-pair.bat`（双进程 8789 + 8790）

在 `hub/server.py` 尚未就绪、但需要「一条命令起双引擎」时用（`%%` 还原规则同 §2.2）：

```bat
@echo off
setlocal EnableExtensions
rem ===========================================================
rem  hub - transitional launcher: two engines, two processes.
rem  wb -> 8789   qd -> 8790   (matches the historical defaults)
rem  ASCII-only; no %%VAR%% inside if( ... ) blocks.
rem ===========================================================

set "HERE=%~dp0"
set "WBPORT=8789"
set "QDPORT=8790"

if not exist "%%HERE%%wb_proxy.py"    goto no_wb
if not exist "%%HERE%%qoder_proxy.py" goto no_qd

rem ---- resolve python (same 4-step ladder) ----
set "PYEXE="
if not exist "%%HERE%%python\python.exe" goto try_path
"%%HERE%%python\python.exe" --version >nul 2>nul
if errorlevel 1 goto try_path
set "PYEXE=%%HERE%%python\python.exe"
goto start

:try_path
python --version >nul 2>nul
if errorlevel 1 goto try_py
set "PYEXE=python"
goto start

:try_py
py --version >nul 2>nul
if errorlevel 1 goto nopython
set "PYEXE=py"
goto start

:nopython
echo [ERROR] No usable Python found (need 3.9+).
pause
exit /b 1

:no_wb
echo [ERROR] wb_proxy.py not found next to this script.
pause
exit /b 1

:no_qd
echo [ERROR] qoder_proxy.py not found next to this script.
pause
exit /b 1

:start
echo Starting both engines in separate windows ...
start "hub-wb :%%WBPORT%%" cmd /k ""%%PYEXE%%" "%%HERE%%wb_proxy.py" --port %%WBPORT%%"
start "hub-qd :%%QDPORT%%" cmd /k ""%%PYEXE%%" "%%HERE%%qoder_proxy.py" --port %%QDPORT%%"
echo.
echo   wb  API/Admin : http://127.0.0.1:%%WBPORT%%/
echo   qd  API/Admin : http://127.0.0.1:%%QDPORT%%/
echo.
echo Each engine runs in its own window; close that window to stop it.
pause
```

**为什么必须分窗口**：两个网关都会写各自的 `usage.jsonl` 与 `accounts/settings.json`；同一控制台里两条日志流会交错，且 `Ctrl+C` 只杀前台进程 ⇒ 单窗口无法干净停两边。

### 2.4 `start-hub.sh` / `start-hub.command`

```bash
#!/usr/bin/env bash
# hub - unified launcher (macOS / Linux)
# Usage: ./start-hub.sh [port]     default 8789
set -euo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"
PORT="${1:-8789}"
SCRIPT="$HERE/hub/server.py"
[ -f "$SCRIPT" ] || { echo "[ERROR] hub/server.py not found next to this script."; exit 1; }

pick_python() {
  for c in "$HERE/python/bin/python3" /usr/bin/python3 "$(command -v python3 || true)" "$(command -v python || true)"; do
    [ -n "$c" ] && [ -x "$c" ] || continue
    if "$c" -c 'import sys; raise SystemExit(0 if sys.version_info >= (3,9) else 1)' >/dev/null 2>&1; then
      echo "$c"; return 0
    fi
  done
  return 1
}
PYEXE="$(pick_python)" || {
  echo "[ERROR] Need Python 3.9+."
  echo "  macOS:  xcode-select --install   or   brew install python"
  exit 1
}

echo "==========================================================="
echo "  hub gateway  (WorkBuddy + Qoder)"
echo "    API   : http://127.0.0.1:$PORT/v1"
echo "    Admin : http://127.0.0.1:$PORT/admin/"
echo "    Python: $PYEXE"
echo "  Keep this window open. Press Ctrl+C to stop."
echo "==========================================================="
exec "$PYEXE" "$SCRIPT" --port "$PORT"
```

`start-hub.command`（双击用）：
```bash
#!/usr/bin/env bash
cd "$(dirname "$0")" || exit 1
./start-hub.sh "$@"
```

### 2.5 `allow-firewall` 合并

两个现有脚本差异**只有默认端口与规则名**：

|---|---|---|---|
| 默认端口 | 8789 | 8790（`qoder/allow-firewall.bat:11`） | **8789** |

## 3. Docker

### 3.1 `Dockerfile` 完整草案

以 `qoder/Dockerfile`（73 行，两阶段已验证）为骨架，补进 wb 侧的两个好东西：`HEALTHCHECK`（`wb/Dockerfile:26-27`）与 `--lan` 启动（`wb/Dockerfile:36`）。

```dockerfile
# hub —— WorkBuddy + Qoder 双引擎融合网关
# 纯标准库：AES/RSA/COSY 签名、GCM、DPAPI、QMC 全部为纯 Python 实现，零 pip 依赖。

# ---------------------------------------------------------------------------
# 构建期：提取 UMID 原生组件（@qoder-ai/qodercli 内嵌的 runtime-info）
# 纯标准库 python 实现（不需要 node）；npm 包只在 builder 阶段存在。
# 提取失败不阻断构建：网关退化为 derived 身份，功能仍可用。
# ---------------------------------------------------------------------------
FROM python:3.11-alpine AS umid-builder
ARG TARGETARCH
WORKDIR /build
COPY _install_umid.py ./
RUN apk add --no-cache ca-certificates && \
    arch="x64"; [ "$TARGETARCH" = "arm64" ] && arch="arm64"; \
    python _install_umid.py --platform linux --arch "$arch" --dest /build/umid || \
    echo "WARN: UMID extraction failed (gateway will fall back to derived identity)"; \
    mkdir -p /build/umid

# ---------------------------------------------------------------------------
```

## 6. 版本号策略

### 6.1 现状：wb 双硬编码，qoder 单一常量

| 侧 | 版本来源 | 实测 |
|---|---|---|
| wb | `wb_proxy.py:2357` `"version": "1.6.17"`（在 `runtime_settings_view` 内）+ `wb_proxy.py:7063` `server_version = "wb-proxy/1.6.17"` + `README.md:4` 徽章 + `README.md:356` changelog | **两处硬编码字面量**，改版本要动 3 个地方 |
| qoder | `qoder_proxy.py:57 VERSION = "1.3.4"` → `:5498 server_version = "qd-proxy/" + VERSION` + `README.md:4` 徽章 | **单一常量派生**，改 1 处 + README |

### 6.2 决策：单一来源 + 派生 + CI 自检

**唯一真源** `hub/__init__.py`：

```python
# hub/__init__.py
__version__ = "2.0.0"
VERSION = __version__          # 兼容两种写法
ENGINES = ("wb", "qd")
```

**派生规则**：

| 位置 | 写法 | 说明 |
|---|---|---|
| `hub/server.py` | `server_version = "hub/" + hub.VERSION` | 替代 `wb_proxy.py:7063` 与 `qoder_proxy.py:5498` 两处 |
| `/health` 与 `/api/hub/version` | `{"version": hub.VERSION, "engines": {"wb": WB_VERSION, "qd": QD_VERSION}}` | **三个版本号都暴露**：融合版本 + 两引擎来源版本（可溯源） |
| `hub/engines/wb/__init__.py` | `ENGINE_VERSION = "1.6.17"   # frozen at merge time` | 冻结为**融合时刻**的引擎版本，之后不动 |
| `hub/engines/qd/__init__.py` | `ENGINE_VERSION = "1.3.4"` | 同上 |
| `README.md` 徽章 | 手写 `2.0.0` | 唯一允许的重复（CI 校验） |
| `docker-compose.yml` | 用 `:latest`，不写版本 | 避免第四处副本 |

**主版本号为什么从 2.0.0 起**：融合同时改变了①数据布局（`data/`）、②路由命名空间（`/api/<engine>`）、③指纹盐串（`hub:<engine>:<salt>`）—— 三者都是破坏性变更。按语义化版本必须进主版本。两引擎的冻结版本（1.6.17 / 1.3.4）在 `/health` 可见，**不丢溯源**。

### 6.3 CI 自检（防版本漂移）

```yaml
      - name: version consistency
        shell: bash
        run: |
          py_ver=$(python -c "import hub;print(hub.VERSION)")
          readme_ver=$(sed -n 's/.*Release-v\([0-9.]*\).*/\1/p' README.md | head -1)
          echo "hub.VERSION=$py_ver  README=$readme_ver"
          test "$py_ver" = "$readme_ver" || { echo "::error::version drift"; exit 1; }
```

> 用 `sed` 而非 `grep -oP`：GNU grep 的 `-P` 在 Git for Windows 上可用但非 POSIX 保证，`sed` 更稳。

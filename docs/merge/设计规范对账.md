# 对账 `modern-frontend-design`（2026 版）· Lead 第 73 轮

## 为什么对这一次

这一轮加载了 `modern-frontend-design` 技能（本会话技能目录里同时提到「design a dashboard」，
与本项目的后台管理页对口）。它的 Step 10 是一张**可直接勾选的验收清单** ——
而清单这种东西，**只有真拿去对一遍才知道自己缺在哪**。

## 逐条结果

| 清单项 | 本项目实测 | 结论 |
|---|---|---|
| 所有颜色用 `oklch(...)` | `--canvas: oklch(13% 0.015 265)`、`--surface: oklch(17% 0.017 265)` … | ✅ 已达标 |
| 组件里零硬编码 hex/rgba | 判据 **V1a/V1b** 在守（且带 `VISUAL_STRICT_TOKENS=1` 严格档） | ✅ 已达标 |
| 圆角全部走 `--r-*` | 4 处例外全是 `border-radius: inherit`（**继承父级，本就该如此**） | ✅ 已达标 |

| **时长全部走 `--dur-*`** | **查出 6 处裸时长**（`1.4s`×3 / `180ms` / `200ms`×2） | ❌ **本轮已补** |
| 每个 modal/toast/drawer 有 `@starting-style` | 实测 **6 处**：`.page` / `.menu` / `.modal-mask` / `.modal` / `.toast` / `.palette__box` | ✅ 已达标 |
| 不用纯黑做背景 | `oklch(13% 0.015 265)` —— 有 265 色相、0.015 彩度 | ✅ 已达标 |
| 每个动画有 reduced-motion 兜底 | 判据 **V6** 在守（「有动效就必须有 prefers-reduced-motion 兜底」） | ✅ 已达标 |

**9 条里 8 条已达标，1 条补上了。**

## 补的那一条：裸时长 → `--dur-*`

```css
/* 改前 */
animation: hub-shimmer 1.4s infinite linear;
animation: hub-card-in 180ms var(--ease-out) both;
animation: hub-row-in  200ms var(--ease-out) both;

/* 改后 */
animation: hub-shimmer var(--dur-shimmer) infinite linear;   /* 新令牌 */
animation: hub-card-in var(--dur-base) var(--ease-out) both;
animation: hub-row-in  var(--dur-base) var(--ease-out) both;
```

**新加的 `--dur-shimmer: 1.4s` 与原有三档的语义区别**：

> `--dur-fast/base/slow` 是**一次性的**（交互、揭示），`--dur-shimmer` 是**周期性的**。
> 前者问「多久完成」，后者问「多久循环一次」—— 混在一起会让后来人不知道该改哪个。

## 技能里我**没有**采纳的三条（附理由）

| 建议 | 不采纳的理由 |
|---|---|
| CSS Anchor Positioning 替代工具提示定位 | 现在用 `::after + left: calc(100% + 10px)`，纯 CSS、零 JS，**已经满足「不要 Floating UI」的本意**；换 anchor 定位要额外处理 `position-try-fallbacks` 的兼容面，收益不成比例 |
| 原生滚动驱动动画（`animation-timeline: view()`）替换入场动画 | 本项目的入场动画**只在切换视图时触发一次**，不是滚动触发的；现有的 `data-painted` 闸门解决的正是「刷新时重复播放」那个真问题 |
| 加颗粒纹理（grain，opacity 0.025–0.045） | 那是给**营销页**增加温度的；后台管理页每屏都是数据表，多一层噪点只会降低数字的可读性 |

## 一句结论

> **技能里那些「硬规则」，本项目多数早就在守 —— 而它们是谁定的并不重要，重要的是有人拿清单来对过一次。**
> 自己写的判据（V1/V6/V7）覆盖了这 9 条里的 4 条，**剩下 5 条靠这一轮人肉对账才发现只差一处**。
> 这说明：**有判据 ≠ 覆盖全了**；清单式对账是另一种互补的手段。

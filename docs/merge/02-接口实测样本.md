## 一、面板鉴权（**关键，与 00 号决策书 §4.1 的初稿不同，以本节为准**）

不是 Cookie 会话，是**自持令牌**：

```http
POST /panel/login      Content-Type: application/json      body: {"password":"<面板密码>"}
→ 200 {"ok": true, "token": "<32 位随机串>", "using_default_password": false}

GET  /accounts         带上：X-Panel-Token: <上一步拿到的 token>
→ 200 {...}
```

- 头部名**必须**是 `X-Panel-Token`（源码：`wb_proxy.py:7448-7456` `_panel_token()`）。
- 令牌**不带 Cookie**、不随浏览器会话自动失效；前端自行持久化（建议 `sessionStorage`，不要 `localStorage`）。
- 未带/令牌失效 → **401**；前端据此统一切到登录态。
- `POST /panel/logout` → 撤销（源码：`wb_proxy.py:8378` `PANEL.revoke(...)`）。

**实测证据**（本机跑通）：
```
POST /panel/login  {"password":"dev123"} → 200 {"ok":true,"token":"-o31Y8zpVOGf7YPTlENIlPN1mSYAOmAE"}
GET  /accounts  带 X-Panel-Token → 200 {"accounts":[],"storage":"…\\hubdev\\accounts","usable":0}
GET  /accounts  不带             → 401
```

## 三、三条读端不变量（写代码前必须知道）

1. **空态是常态**：新装的实例里 `accounts/usage/models` 等都会返回空数组或 0，而 `usage/perf` 的各项
   指标是 `null`（不是 0）——例如 `success_rate_pct:null`、`ttft_ms:null`。**渲染 `null` 要显示「—」，不能显示 0。**
2. **`usage.recent.rows` 里同一张表有成功行与错误行两种形状**：成功行带 `prompt_tokens/completion_tokens/…`，
   错误行带 `error/outcome/status/message`（见 `docs/recon/*` 对 `usage.jsonl` 的字段统计）。
   表格渲染必须**按行判型**，缺字段显示「—」。
3. **`/models` 是合并的最难点**：wb 返回 `{"object":"list","data":[...],"realm":"intl"}`，
   每个模型带 `context_length/max_output_tokens/reasoning_efforts/capabilities/credits` 等**大量规格字段**（实测 21 KB / 20 条）。
   合并后要返回**两引擎并集**并给每条打 `engine` 标记，视图按 engine 分组或加筛选，不要混排成一锅。

## 四、复现命令（任何人可重跑）

```powershell
# 1) 起隔离实例（绝不使用 8789）
cd <workspace>\wb
python wb_proxy.py --port 8799 --accounts-dir "$env:TEMP\hubdev\accounts" `
                   --usage-dir "$env:TEMP\hubdev\usage" --panel-password dev123
# 2) 取令牌
$login = Invoke-RestMethod -Uri "http://127.0.0.1:8799/panel/login" -Method POST `
          -Body '{"password":"dev123"}' -ContentType "application/json"
# 3) 带令牌取数
Invoke-RestMethod -Uri "http://127.0.0.1:8799/accounts" -Headers @{ "X-Panel-Token" = $login.token }
```

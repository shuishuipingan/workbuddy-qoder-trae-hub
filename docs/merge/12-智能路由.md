# 智能路由（合并层 + 双引擎单侧）· 2026-10-14

> 需求（老板原话）：合并里的 key 一个就打国内+国际 × wb+qoder；同名模型合并；
> **默认国内优先，国内额度/账号用完自动回退国外**；单独 wb / 单独 qd 同理；
> 回退链还要能退到 qoder。

## 一、三层各自负责什么

| 层 | 文件 | 职责 |
|---|---|---|
| **合并层（hub）** | `hub/core/router.py` `hub/core/settings.py` `hub/core/portal.py` | 合并 Key → 候选矩阵 (引擎×区域) 逐个尝试；同名模型合并清单；路由偏好可配 |
| **wb 引擎** | `wb_proxy.py` `wb_settings.py`（v1.7.4 + 本地智能换区补丁） | 单引擎一个 key 双区：cn 优先、池空/429 自动回退另一区 |
| **qd 引擎** | 上游 1.4.0 原生 AUTO_REALM | 同上（独占表 → 清单 → 账号可用性回退），零改动 |

## 二、合并层路由矩阵（portal）

```
候选排序：区域外层 × 引擎内层
  realm 顺序 = prefer_realm(默认 cn) → 另一区
  同区内引擎 = engine_prefer: auto(就绪账号多者先, 并列 wb 先) | wb | qd

默认链:  wb:cn → qd:cn → wb:intl → qd:intl     ← "退回到 qoder" 在链上
钉 intl: wb:intl → qd:intl → wb:cn → qd:cn     ← 客户端 ?realm=/X-Realm 被尊重为首选区
独占模型: 只进它存在的那条链（如 cantus → qd:intl 直达）
```

- **快照**（TTL 8s）：两引擎 × 两区的 /v1/models + /health 就绪数；本地回环探测。
- **重试语义**：401/429/502/503/504 且还没成功 → 换下一个候选（请求体已在手，安全重放）。
- **realm 权威**：客户端的 realm 参数与 X-Realm 头被**剥掉**，由 hub 按候选拼唯一
  `?realm=`（防 `realm=intl&realm=cn` 重复参数 → 头与实际行为对不上的假合并）。
- **双层回退**：hub 钉区后，引擎自身的 auto-realm 仍可在区内耗尽时再换区成功服务 ——
  对用户更友好；`X-Hub-Route` 以引擎回包的 X-WB-Realm/X-Qoder-Realm 为准（真实服务区）。
- **响应头**：`X-Hub-Route`（最终 引擎:区域）、`X-Hub-Route-Attempts`（完整尝试链 JSON）。
- **合并模型清单** `GET /api/v1/models`（合并 key）：同名合一条，带 engines×realm 与
  realm_exclusive；实测 wb36+qd31 → 去重 41 条。
- **合并 key 语义**：hub/settings.json 的 merged_keys 只是「允许走智能路由」的门票；
  同一把 key 必须同时注册在 wb 与 qd 的 API Key 里（各引擎自校验；某引擎 401 → 换下一个）。
  非合并 key 走旧路径（默认引擎），行为零变化。

## 三、wb 单引擎智能换区（本地补丁，上游未含）

- `wb_settings.realm_routing()`：{enabled: 默认开, prefer: 默认 cn}；env `WB_AUTO_REALM=0` 总关。
- `realm_candidates(model, requested)`：独占模型只走所属区；显式区尊重但池空可回退；
  自动模式 prefer 区就绪数为 0 且另一区 >0 时**预先换序**（不白撞一次失败）。
- `Handler._open_upstream_auto()`：仅在 RuntimeError("no usable account")/RateLimited
  （额度耗尽、模型频控）上换区；403/4xx/502 不换（换了也一样错）。
- 可见性：响应头 `X-WB-Realm` / `X-WB-Realm-Reason`；用量行 `realm_reason`；
  `/realm` 增加 auto_enabled / auto_env / prefer；设置页可存 realm_routing。
- 三协议（chat/completions、responses、messages）同口径。

## 四、实测记录（2026-10-14，hub pid 20148）

| 场景 | 结果 |
|---|---|
| 合并 key + glm-5.3-flash（双引擎同名） | 200 route=wb:cn（cn 优先 + wb 就绪 27>3） |
| 合并 key + cantus（qd 独有 intl） | route=qd:intl（跨引擎直达） |
| 合并 key + ?realm=intl / X-Realm:intl | 首选 intl；wb intl 池空 → 引擎回退 cn 成功，X-Hub-Route=wb:cn 与 X-WB-Realm 一致 |
| wb 直连 8811 未绑定 key 无 header | 200 X-WB-Realm: cn（prefer 生效） |
| wb 直连 + X-Realm: intl（intl 池空） | 200 X-WB-Realm: cn + Reason: no_account（自动回退） |
| wb 直连 gpt-5.5（intl 独占、池空） | 503 不跨界（独占模型不换区） |
| wb 直连 deepseek-v4-pro + 钉 intl | 400 跨区错误（原语义保留） |
| qd 直连 8812 未绑定 key | 200 X-Qoder-Realm: cn（原生 AUTO_REALM） |
| stub 集成：wb 恒 503 | 合并请求自动退 qd:cn 200，attempts 链完整（F02-F07 18 判据） |

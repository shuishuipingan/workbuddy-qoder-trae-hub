# 15 · 一个产品怎么用（大白话版）

> 这份文档不讲架构，只讲**你要做什么**。技术细节看 `README-HUB.md` 和 `13-统一Key.md`。

## 一、就记一个地址

```
面板：http://127.0.0.1:8817/
API ：http://127.0.0.1:8817/api/v1
```

**只有这一个地址。** 两个引擎（WorkBuddy / Qoder）都在它后面，你不用再记 8789 / 8790。
（打开 8811、8812 也会自动跳到这个面板——那是内部端口。）

## 二、三种情况，三种用 key 的方式

### 情况 1：我手上只有 WorkBuddy 的 key

直接用，不用改任何东西：

```bash
curl http://127.0.0.1:8817/api/v1/chat/completions \
  -H "Authorization: Bearer <你的 wb key>" \
  -d '{"model":"...","messages":[{"role":"user","content":"hi"}]}'
```

它**只会走 WorkBuddy**，也只能看到 WorkBuddy 的模型。Qoder 那边不会有任何消耗。

### 情况 2：我手上只有 Qoder 的 key

同样直接用，同一个地址。它只会走 Qoder。

### 情况 3：我想要"一把 key 调所有"

到面板 **设置 → 入口：统一 Key 与路由 → 合并 key**，点「＋ 新增合并 key」，复制弹窗里那串密钥。

这把 key：

- 能看到**两边全部**模型（同名的只算一个）
- 自动挑路：先国内、再国际；国内两边都空了才去国际
- **不需要**你在 WorkBuddy 和 Qoder 里再各登记一遍——它会自己换成那台引擎自己的 key

## 三、面板怎么用（七页，各管一件事）

| 页面 | 它回答什么 |
|---|---|
| **总览** | 现在整体什么状态：几个账号、今天用了多少、两个引擎在不在线 |
| **福利中心** | 两边的签到/任务在哪领、还能领什么 |
| **账号池** | 有哪些账号、哪个可用、哪个被停用、加账号/导入账号 |
| **模型清单** | 现在能用哪些模型、各在哪个引擎、多少钱 |
| **数据指标** | 请求量、成功率、token、花费、慢在哪 |
| **请求流水** | 每一条请求的明细（哪天、哪个模型、多少 token、扣多少） |
| **设置** | 限额、定价、key、密码、调度器，以及**自检**和**试打** |

## 四、出问题先看这三个地方

1. **顶栏右上角**：`双引擎 2/2 在线` —— 不是 2/2 就鼠标悬停，它会说 `未就绪：qd`。
2. **页面顶部的黄色横幅**：比如「「qd」侧没有返回数据」—— 说明**下面所有数字只统计了另一半**，不是全量。
3. **设置 → 系统自检 → 开始检查**：17 条逐条 PASS/FAIL，直接告诉你哪一环没接上（含"配置文件坏了"这种）。
   想留证据就点「生成体检报告」，会给你一段可复制的文字。

想验证"我这把 key 到底通不通"：**设置 → 试打**，选 key 类型、填模型、点「发一条」，
它会显示 `PASS 200 · 1800 ms · wb:cn` 这样的真实结果（会花掉一点点额度）。

## 五、哪些是"故意各一份"的

这些**不是没合并**，是本来就该分开：

| 项目 | 为什么分开 |
|---|---|
| 面板密码 | 每个引擎自己有登录口令；面板登录一次三边通用 |
| 限额护栏 | 每个引擎的账号池独立。想一次改两边 → 打开「同时写入两个引擎」再保存 |
| 调度器（定时签到等） | 两边各自跑各自的时刻表 |
| 定价 / 出站提示词 | **只有 WorkBuddy 有**这套东西，所以标了「仅 WorkBuddy」 |
| 引擎设置页的分段 | 切的是"**正在改哪一份**"，页头会写「当前编辑：WorkBuddy」 |

## 五·补 · 英文界面下为什么还有中文

界面文案是**双语**的（右上角可切 EN）。但下面这些仍然会是中文，因为它们是**数据**不是文案：

- 运行日志行（引擎写的）
- 调度器摘要（引擎返回的 "整点排程 …"）
- 福利页的"未找到可用账号"之类**原因串**（引擎返回的）

判据 W44 钉住的是"新增文件里不许有裸中文文案"，界面上这几处属于后端文本，不在其列。

## 六、常见疑问

**Q：我打开 8789 / 8811，跳到一个面板了，是不是坏了？**
不是。融合模式下引擎端口会 302 到控制台（一个产品一张脸）。要直连引擎调试，用 `/api/wb/...`、`/api/qd/...`。

**Q：总览的数字只有一半？**
看顶部黄条 / 顶栏在线数。有一边没起来时，页面会明说"只统计了另一半"。

**Q：合并 key 加进去，客户端还是 401？**
先跑自检看 `合并 key` 那条。也可能是客户端把 key 放错了位置（要用 `Authorization: Bearer <key>`）。

**Q：我在引擎面板里删了 key，合并 key 还能用吗？**
能。合并 key 只是"调用许可"，它借用的是那台引擎**任意一把启用的 key**；引擎里一把都没有时才会失败（自检会红）。

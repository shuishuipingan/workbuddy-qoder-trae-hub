本地 web 工具

开启后，客户端声明的内置 web_search / web_fetch 会由网关本地执行： 把声明换成同名 function，模型要搜索时网关去搜（DuckDuckGo → Bing → Wikipedia 轮换）、要抓页面时网关去抓， 再把结果回灌给模型继续生成（最多 3 轮）。
注意：这是唯一会由模型驱动出网的能力；每轮代跑都会多消耗一次账号额度； 私网地址、localhost、重定向到内网一律拒绝。默认关闭。

事实性限额护栏

三个作用域：全局默认对所有账号生效；国际版 / 国内版 留空 = 继承全局，填 0 = 关闭该区域的这条护栏（0 不是「限制为 0」）。 阈值 ≤ 0 的护栏完全不生效；计数未知时按放行处理（fail-open），账号行会如实标成「未知」。
